# 0003 · Look

Status: accepted, 2026-11-11. Reference: CoreHub's look (`D:\Github\corehub\docs\adr\0004-look.md`, `app/assets/css/main.css`), used as a model, not copied.

## Taken from CoreHub (the system)

- Terminal-inspired; Nord-style grey base in dark mode, a cool light theme.
- Inter for UI, JetBrains Mono for code, shipped with the app.
- Outlined buttons with a visible hover and the hand cursor.
- Colours only as semantic tokens (Nuxt UI `--ui-*`), never raw hex or palette colours in components.
- WCAG AA contrast for text and accents in both themes.

## Grindstone's own

- Accent: a warm ember / spark orange (a grindstone throwing sparks) instead of CoreHub's lime.
- Monospace carries much more of the UI: terminal, graph labels, goals.
- A separate branch palette of 6–8 colours, contrast-checked in both themes, shared by the graph and the terminal output so a branch has one colour everywhere.
- A thin "spark" effect on a new commit and when a level is solved (respects reduced motion).
- Dark theme first, light theme equal in quality.
